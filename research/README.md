# Investigación

Este directorio registra preguntas científicas, fuentes primarias y decisiones aún no convertidas en requisitos de producto.

La investigación no bloquea el primer vertical slice salvo que revele un riesgo de representación engañosa. Las conclusiones deben distinguir evidencia, modelo, cálculo e interpretación.

Áreas iniciales:

- contrato ampliado y procedencia individual de eventos INPRES;
- definición y límites de Slab2 South America;
- preparación y limitaciones de GEBCO;
- tectónica regional y secciones científicas predefinidas;
- cartografía territorial oficial argentina.

La nota sobre metadata individual de INPRES se conservó en `../archive/2026-09-pre-mvp/research/inpres.md`. Es trabajo postconcurso y no bloquea el MVP.
